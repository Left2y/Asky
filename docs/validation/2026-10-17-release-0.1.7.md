# Asky 0.1.7 Release

日期：2026-10-17。以上一已发布版本 v0.1.6 为基准递增 patch，构建号 31（从上一版 ZIP 读取构建号 30）。macOS 15+、Apple Silicon。

## 更新内容

打包源码及包内 KHReleaseCommit：`17b90a912474d747aeedbfe0e7886453a04dfea6`。打包前工作区干净，源码已提交。
