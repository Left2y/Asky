## 实际运行

```sh
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Release -derivedDataPath build/Release009DerivedData ARCHS=arm64 ONLY_ACTIVE_ARCH=YES build
(cd AgentRuntime && npm test)
npm ci --omit=dev --prefix build/release-runtime-0.0.9
python3 scripts/package-release.py --version 0.0.9 --build 9 --derived-data build/Release009DerivedData --runtime build/release-runtime-0.0.9 --node-root build/node-v22.23.3-darwin-arm64
```
