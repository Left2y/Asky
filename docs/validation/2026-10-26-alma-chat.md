# Alma 原生聊天集成验证

当前实现任务延续：`alma` 进入 Asky 内的聊天窗口，绑定 Alma 的持久线程，支持连续问答、流式展示、停止及在 Alma 打开；启动器使用插件声明的真实图标。Alma 本体和 /Applications/Asky.app 不修改。

## 构建与隔离约束

- 本机只有 CLT Swift 6.3.2 / SDK 26.5；`NSMenuItem.preferredImageVisibility` 需要 SDK 27，运行时 availability 不能补足编译 SDK。
- App 构建交给个人 fork 的 GitHub Actions：`runs-on: xcode-27`，`DEVELOPER_DIR=/Applications/Xcode_27.1.app/Contents/Developer`。
- 执行 `xcodegen generate` 后执行 `xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Debug -destination 'platform=macOS,arch=arm64' CODE_SIGNING_ALLOWED=NO`。
- 本地 core 测试使用 `swift test --triple arm64-apple-macosx14.0`。
- 独立产物目标：`outputs/Asky-Alma.app`，复用原安装中只读资源，替换为新主程序，ad-hoc 签名。
- 开发版必须使用独立数据 root 与 Keychain service，禁用默认全局快捷键、登录启动、更新及 MCP listener，保留 KHSourceRoot；原安装及原配置不写入。
