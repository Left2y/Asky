# DMG 安装界面样式

## 改动

- 浅蓝紫背景、Asky 标题、中文安装说明与拖拽箭头。
- 660 × 440 点的背景使用包含 1× / 2× 图层的 TIFF，适配 Retina。
- Finder 中将 Asky 放在左侧、Applications 放在右侧，图标大小为 88 点；隐藏工具栏、状态栏和路径栏。
- 打包脚本先创建可写 HFS+ 镜像，挂载后由 Finder 保存布局；检查 `.DS_Store`，卸载后转换为 UDZO。错误时仍尝试卸载镜像。

## 已执行验证

- `python3 scripts/package-release.py --help` 成功；Python AST 解析通过。
- `osacompile -o build/dmg-layout.scpt scripts/dmg/layout.applescript` 通过。
- 在 `build/dmg-style-preview/` 中复制已有构建的应用并添加 Applications 链接与背景，实际运行布局脚本成功。
- 关闭后重新打开 Finder 预览目录，确认 `.DS_Store` 已写入，背景和图标位置保留。
- 使用 Orca computer-use 检查真实 Finder 窗口：Retina 文字清晰、图标与卡片及箭头对齐、底部说明完整可见。截图保存在 `build/dmg-style-preview.png`（本地验证产物，不纳入 Git）。
- `git diff --check` 通过。

## 验证边界

本轮未重新构建应用、创建 Release DMG / ZIP、发布或安装。Finder 检查使用本地目录；可写磁盘镜像的挂载、压缩转换及在另一台机器打开的效果尚未实际验证。窗口的标签栏仍受 Finder 本机偏好影响。
