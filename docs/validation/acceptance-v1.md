## 开始前

1. **构建。** 运行 `cd AgentRuntime && npm run build`，再运行 README 中的 `xcodegen generate` 和 `xcodebuild` 两条命令。
2. **启动。** 用 `open build/DerivedData/Build/Products/Debug/KulaHere.app` 启动。App 没有 Dock 图标，入口在菜单栏的放大镜图标。
3. **注意授权会失效。** 当前是 ad-hoc 签名，每次重新构建后签名都会变，系统授权（日历、通讯录、自动化、屏幕录制）可能需要重新授予。验收期间尽量不要重新构建。
4. **数据位置。** 数据在 `~/Library/Application Support/KulaHere/`，Pi 的日志在其中的 `runtime-stderr.log`。
5. **查看进程。** 用 `pgrep -lf "KulaHere|dist/src/main.js"` 查看 App 和 Pi 进程。

已知缺口（验收前已确认，预计不通过）：A11、A12、A13、A15、A27 中的删除联动部分、A05 中的授权粘贴，以及“使用当前选择”附件。
