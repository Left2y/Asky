# 首次启动欢迎窗口

日期：2026-10-24。

## 实现

- SwiftUI 内容由普通 AppKit NSWindow 承载，760 × 520 pt。沿用 WindowPresentation 的激活和窗口层级规则。
- 原创连续 Bézier 路径以 2.8 秒描绘 hello，蓝紫粉橙渐变描边；背景为模糊椭圆色彩，8 秒往返漂移。欢迎标题淡入，按钮从出现起即可操作。
- 从 SwiftUI 环境读取 Reduce Motion：开启时直接显示完整路径与标题，背景静止。深浅色跟随外观，中英文使用现有本地化资源。
- 全新偏好默认 `hasCompletedWelcome = false`；已有偏好缺少该字段时迁移为 true。点击开始通过现有 AppModel 偏好存储保存完成状态，再进入启动器。关闭欢迎窗口不写完成状态，再次打开应用时仍可显示。
- 关闭窗口移除 NSHostingView，释放动画内容。欢迎窗口可见时不满足自动更新的静默重启条件。
