# Asky 0.1.3 Release

日期：2026-10-16。以上一已发布版本 v0.1.2 为基准，patch 递增至 v0.1.3，构建号 27。macOS 15+、Apple Silicon。

## 更新内容

修复浮动玻璃窗口的黑边与玻璃变深问题，采用 Spotlight 式独立窗口；主动提醒改为自绘卡片；支持从短信预约建议确认或修改后创建日历事件。更新 README 的使用教程入口、官方插件链接、演示与产品对比。
