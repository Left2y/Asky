# MapKit 交通方式推荐策略

日期：2026-10-19。用户反馈地图工具可用，但 Agent 经常推荐驾车或打车。

## 调整

现有指引只要求考虑已确认偏好，没有为偏好未知时明确选择策略。此次补充 Agent Runtime 指引：

- 优先采用用户明确要求与已确认偏好，不假设用户有车或愿意打车。
- 未指定方式时比较步行、公交、驾车；不能只查驾车，也不能按结果顺序或仅按最短耗时推荐。
- 短距离且时间合理时优先考虑步行；公交能按时到达且耗时相近时优先考虑公交，依据工具结果与日程间隔说明理由。
- 自驾主方案需要用户明确有可用车辆或要求自驾；打车作为有条件的备选，不能把 driving 结果标成含等车时间的打车总耗时。
- 公交查询失败只表示本次无有效估计，不等于当地没有公交，不能推导为只能驾车或打车。

README 中英文和原生工具专题同步这一策略。未修改 Swift 工具或路线计算，不改用户偏好数据，也未将本次反馈写入长期记忆。
