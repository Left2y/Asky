# 机动车方案默认优先打车

日期：2026-10-19。根据用户进一步澄清，修正上一轮将打车限为备选的指引。

- 步行、公交、机动车仍按用户偏好、真实路线耗时与日程间隔比较；机动车方案默认先考虑打车，不假设用户有车。
- `driving` 代表道路行驶耗时，不直接代表自驾意图。打车是正常候选，不必等到公交不可用时才考虑。
- 只有用户明确选择自驾且车辆可用时才规划自驾，并考虑停车、找车位及停车后的步行；仅有“用户有车”的信息不足以默认推荐自驾。
- 自有车辆位置约束仅适用于自驾；打车不产生车辆遗留问题。
- 打车将工具耗时标注为预计行驶时间，未知等车、上下车时间单独说明，不编造总耗时。
