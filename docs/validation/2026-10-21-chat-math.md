# 聊天公式渲染验证

## 改动

- 共享聊天 Markdown 入口先提取 LaTeX，再交给原有 MarkdownUI 渲染；存储及整条消息复制仍使用原始 Markdown。
- SwiftMath 1.7.3 在本地排版，支持 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`，独立公式可横向滚动。
- 行内公式使用原生文本附件与数学基线；浅色、深色使用对应文字色。公式图片缓存限制为 256 项、32 MiB。
- 跳过行内代码、围栏代码、缩进代码、转义符与 Markdown 链接目标；普通金额、未闭合公式保持原文。独立公式不跨空段匹配，避免说明中的孤立 `$$` 吞掉后面的公式。
- 无法解析的公式显示源码。原生行内文本正确响应 SwiftUI 的最小、最大宽度测量，按实际段落宽度换行。
- 数学字体资源及其许可由 SwiftPM 随 App 打包，SwiftMath MIT 许可放入 `ThirdParty/SwiftMath`。

## 范围

原生回归使用真实 `ChatMarkdownView` 和 NSWindow，不请求模型，也不改动用户历史。尚未使用在线模型逐字流式输出或实际用户历史做端到端验证；宏定义、任意 LaTeX 文档命令不在支持承诺内。
