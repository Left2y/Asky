# Asky 0.0.19 Release

日期：2026-10-13。版本 0.0.19/build 19，macOS 15+、Apple Silicon。

以上一已发布版本 v0.0.18 为基准递增 patch。本次将发布包改用固定的 `Asky Local Signing` 证书，保持主应用与内置执行文件的签名身份连续。证书仅包含产品签名名称；私钥保存在登录钥匙串，不进入分发包。证书 SHA-1 为 `BBCC4AB3786640961FFD5BF63808AD00761AFB3B`。
