# Markdown 样式、图片下载与代码复制

日期：2026-10-11。

## 实现

- 行内代码通过原生 NSTextView／NSLayoutManager 绘制 Neutral 背景、4 pt 圆角及参与排版的左右空格内距，使用 13 pt 等宽字体，保留文本选择、链接与自动换行。行内图片高度 14 pt，基线偏移 -2 pt；图片独立段落继续走原有图片视图。
- 图片右下角 32 pt 下载按钮保存原图到 Downloads，加载过程中禁用，完成显示勾，失败显示错误。读取和写入在 ToolService 模块中完成，继续遵守 10 MiB 下载上限；根据真实图片类型选择扩展名，同名文件用数字后缀避免覆盖，下载不使用 1600 px 展示缩略图代替原图。
- 代码块标题栏左侧显示围栏语言，没有语言时显示 Code；右侧复用消息复制的 ChatCopy SVG、16 pt 图标、28 pt 点击区域及 AgentIconButtonStyle，复制完整原代码，显示 800 ms 勾反馈。
- 表格保留 8 pt 圆角外框，内部仅横向分隔线；表头 backgroundNeutral，正文无交替背景。单行最小高度 32 pt，换行可增高。Grid 列间距设为 0，消除白色竖缝。超宽内容由横向 ScrollView 承载。
