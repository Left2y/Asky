# Asky 使用教程

Asky 把应用和文件搜索、剪贴板历史、计算与 AI 助手放在几个随时可以唤起的窗口里。这份教程面向首次使用的用户，不需要编程基础。

更新日期：2026 年 10 月 13 日。本文按当前仓库的界面与功能编写，已发布安装包可能尚未包含最新改动。搜索、剪贴板和计算无需配置 AI；AI 对话需要你自己的模型服务配置，系统操作还需要对应授权。

## 安装与首次使用

当前发布包适用于 macOS 15 或更新版本、Apple Silicon Mac。

1. 从 [Asky 下载页面](https://github.com/Niall-Young/Asky/releases)选择版本，下载名称以 `.dmg` 结尾的安装包。ZIP 用于应用内更新，首次安装使用 DMG。
2. 打开 DMG，把 `Asky.app` 拖到旁边的“应用程序”入口。
3. 从“应用程序”启动 Asky。若从下载目录或 DMG 中启动，按应用提示“安装并重新打开”。
4. 点击菜单栏中的 Asky 图标，可以打开搜索、剪贴板历史、AI 对话和设置。
5. 按 `Option + Space` 打开搜索，输入一个已安装的应用名，选中后按回车。

完成第 5 步，就可以开始使用本地功能了。需要日常随开机使用时，在“设置 › 通用 › 启动”打开“登录时启动”。

### 先记住这几个快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 打开搜索启动器 | `Option + Space`（`⌥ Space`） |
| 打开剪贴板历史 | `Control + Shift + C`（`⌃⇧ C`） |
| 打开 AI 的空白新对话 | `Control + Shift + /`（`⌃⇧ /`） |
| 在搜索、剪贴板或 AI 窗口打开设置 | `Command + ,`（`⌘,`） |
| 在搜索结果中选择 / 执行 | 方向键 / 回车 |
| 关闭搜索或剪贴板面板 | `Esc` |

在“设置 › 触发快捷键”点击对应快捷键，再按下新组合键即可修改。提示“已被占用”时换一个组合键，也可以使用菜单栏入口。

## 搜索应用和文件

### 打开应用

1. 按 `Option + Space`。
2. 输入应用名，例如 `Safari` 或 `备忘录`。
3. 用上下方向键选中目标，按回车打开。

未输入内容时，搜索框右侧会显示固定和筛选按钮。固定可让窗口在切换应用时保持可见；筛选可只看应用、文件、快捷方式或系统快捷指令。选择“全部”恢复混合搜索。关闭窗口后，固定和筛选状态会重置；筛选菜单打开时，第一次按 `Esc` 先关闭菜单。

### 找到自己的文件

1. 打开“设置 › 通用 › 文件搜索范围”。
2. 点击“添加文件夹…”，选择存放文件的目录，例如你的项目资料文件夹。
3. 重新打开搜索，输入文件名中的一部分。
4. 选择正确结果后按回车打开。

找不到文件时，先确认所在目录已添加，且文件仍在原位置。需要让 AI 参考某个文件时，可在对话中主动添加该文件为附件。

### 给常用应用或快捷指令起别名

在“设置 › 别名与快捷指令”中，填写短别名，选择“应用”或“快捷指令”及对应目标，再点击“保存别名”。例如给 Safari 保存别名 `sf`，之后在搜索框输入 `sf` 即可找到它。快捷指令列表为空时，先在系统“快捷指令”应用中创建，再点击“刷新快捷指令”。

## 网页、书签与终端指令

### 用关键词打开网页搜索

在搜索框输入“指令 + 空格 + 内容”，选择指令结果并按回车：

| 输入示例 | 用途 |
| --- | --- |
| `go macOS 快捷键` | Google 搜索 |
| `chat 帮我写一封会议邀请` | 在浏览器打开 ChatGPT 并带入问题 |
| `yt SwiftUI 教程` | YouTube 搜索 |
| `dy 做饭` | 抖音搜索 |
| `tb 键盘` | 淘宝搜索 |
| `jd 显示器` | 京东搜索 |
| `bl 摄影入门` | bilibili 搜索 |
| `gh swift launcher` | GitHub 搜索 |

这些是固定内置指令，可在“设置 › 指令”查看，不能自行添加、修改或删除。`chat` 打开的是浏览器中的 ChatGPT；Asky 内的 AI 助手使用单独的模型设置。

### 搜索 Chrome 书签和标签页

书签需要先授权：

1. 打开“设置 › 系统权限 › Chrome 书签与链接搜索”。
2. 点击“去授权”，在系统选择器中选择 Chrome 文件夹，或其中的 `Default` / `Profile` 个人资料文件夹。
3. 保存授权后，重新打开搜索，输入 `bm 关键词`，例如 `bm 设计`。
4. 选择书签后按回车打开。

未授权时，书签与链接搜索入口不会出现，`bm` 也不会进入书签模式。Asky 仅读取本地和账号书签，不读取浏览历史。

切换已打开的 Chrome 标签页时，保持 Chrome 运行，输入页面标题中的关键词，选择对应标签页结果。若提示权限不足，按提示允许 Asky 自动化控制 Chrome，并检查“设置 › 数据来源”的“Chrome 标签与书签”。

### 在终端执行命令

1. 在“设置 › 指令 › 终端”选择执行命令的终端和工作目录。
2. 打开搜索，输入英文 `>`，再按空格进入终端模式。
3. 输入 `pwd`，按回车：Asky 会打开所选终端，在配置的工作目录执行命令。

完整输入示例是 `> pwd`。`>` 和命令之间必须有空格；单独的 `>` 或 `>pwd` 会保持普通搜索。首次使用可能需要允许自动化控制终端。终端模式中，输入框为空时按退格可退出。

## 计算与汇率换算

直接在搜索框输入算式即可看到结果：

| 输入 | 结果或用途 |
| --- | --- |
| `1+1` | `2` |
| `2(3+4)` | `14`，支持省略乘号 |
| `sqrt(81)` | `9` |
| `2^3` | `8` |
| `100*20%` | `20` |
| `100 USD CNY` | 查看 100 美元换成人民币的金额 |
| `100人民币` | 查看人民币换成美元，并展示其他币种结果 |

算式结果可按回车复制；汇率卡片仅展示换算，没有复制或选中操作。汇率使用 ECB 日参考数据，有缓存时断网仍可计算，无缓存时会显示不可用；结果不代表实际交易报价。

## 使用剪贴板历史

### 找回刚才复制的内容

1. 确认“设置 › 通用 › 剪贴板”的“记录剪贴板历史”已开启，并保持 Asky 运行。
2. 在其他应用复制一段文字、一张图片或 Finder 中的文件。
3. 按 `Control + Shift + C` 打开历史。
4. 输入关键词筛选，或用方向键选择卡片；悬停约 1 秒可查看完整预览。
5. 点击卡片或使用右键菜单中的“复制”，再回到目标应用按 `Command + V`。

授予辅助功能权限后，选中卡片按回车可以复制、关闭面板并直接粘贴到此前的应用。没有该权限时，使用“复制”后手动粘贴。

图片、文字和文件还可以从卡片拖到支持对应内容的应用；文件支持整组复制和拖出。拖出不会改写系统剪贴板。文件历史保存原路径，原文件移动或删除后需要重新复制。

### 保留常用内容、清理历史

- 右键卡片，选择“固定记录”，保留常用内容；需要时可“取消固定”。
- 右键选择“删除”，只删除这条历史记录，不删除原文件。
- “设置 › 通用 › 剪贴板 › 清空未固定的剪贴板历史”可批量清理，固定记录会保留。
- 关闭“记录剪贴板历史”可停止新增记录。可在同一页填写需排除应用的 Bundle ID，多个 ID 用逗号分隔。

面板右上角的“固定窗口”控制窗口是否保持可见，与“固定记录”是两个独立操作。

## 配置和使用 AI

### 配置模型

1. 打开“设置 › 智能配置”。
2. 选择供应商：OpenAI、DeepSeek，或“自定义（OpenAI 兼容）”。
3. 按模型服务提供的信息填写 HTTPS API 地址、准确的模型名和 API Key。API 地址填写服务的基础地址，不填写完整的 `chat/completions` 请求路径。
4. 点击“保存并检查”。首次配置必须填写 Key；之后留空会保留已保存的 Key。保存后会立即检查文本、图片和工具能力，结果显示在下方“模型能力”中；检查会向模型服务发送少量实际请求。配置未改动时，按钮变为“重新检查”。
5. 打开 AI 对话，发送“请用一句话介绍你能帮我做什么”，确认能收到回复。

API Key 保存在 macOS 钥匙串中。图片理解和系统工具操作分别依赖模型的图片与工具调用能力；能聊天不代表具备这两项能力。模型使用和费用遵循你所配置服务的规则。

### 开始一项任务

使用菜单栏“AI 对话”或 AI 快捷键打开窗口，输入请求并发送。例如：

> 帮我把下面这段文字改成简洁的会议邀请：……

需要参考图片或文件时，点击输入框旁的附件按钮（“选择文件或图片”），选择附件后再发送。历史对话可从对话窗口的历史入口重新打开；AI 快捷键每次会开启空白新对话，正在回复时会先取消旧任务。

发送按钮旁可以切换审批模式。默认“自动审批”会直接执行查询和明确要求的创建；修改、删除、发送等操作会弹窗确认，AI 自行推断的写入只作为建议。确认时核对目标、内容和时间，需要更多信息可展开“操作详情”。“完全访问权限”会让 Asky 内 AI 的工具调用直接执行，设置会持续影响所有对话；数据来源开关和系统授权仍然有效。

AI 可搜索公开网页，无需额外搜索 Key。在“设置 › 数据来源 › 联网搜索”关闭“允许 AI 搜索公开网页”可停用。搜索词发送给 Bing，结果摘要发送给配置的模型服务；摘要不等于已读取网页全文。

## 连接日历、提醒事项和备忘录

系统功能通常需要两步：在“设置 › 数据来源”启用对应来源，再在“设置 › 系统权限”授予 macOS 权限。只配置模型不会自动获得系统访问权限。

### 创建一个提醒事项

1. 在数据来源中启用“提醒事项”，授予提醒事项权限。
2. 在 AI 对话中输入：“明天下午 3 点提醒我给客户发报价。”
3. 若需要补充列表或确认信息，按界面提示操作。
4. 看到执行结果后，打开系统“提醒事项”检查标题和时间。

日历也可以这样使用，例如：“查看明天的日程”，或“在我的可写日历中创建明天下午 2 点到 3 点的项目讨论”。涉及多个日历或冲突时，先确认目标与安排。

### 选择 AI 可以访问的备忘录文件夹

1. 在“设置 › 数据来源”启用“备忘录”。
2. 在“授权的备忘录文件夹”点击“连接备忘录”，按提示允许自动化访问。
3. 勾选允许访问的文件夹，选择会自动保存。未勾选的文件夹内容不会被读取。
4. 在 AI 对话中输入：“在我授权的备忘录里查找关于项目复盘的内容。”

找不到文件夹时，先在 Apple 备忘录中确认账户和文件夹存在，再点击“刷新文件夹”。

### 准备信息草稿

启用“通讯录”和“信息（查询与草稿交接）”后，可请求：“帮我给某位联系人准备一条信息，说明我会晚到十分钟。”联系人不明确时先选择正确的人。草稿交给系统信息应用，最终发送由你在信息应用中完成。

读取历史短信是单独功能：在“设置 › 数据来源 › 短信读取”开启“让 AI 读取最近 30 天的短信与 iMessage”，并授予完全磁盘访问。之后可按关键词与日期查询最近 30 天的本机消息，不需要开启后台 AI 判断。查询结果会发送到模型服务，验证码短信会过滤、长数字会遮盖。

## 记忆与情境提醒

### 开启与查看记忆

1. 配置并保存可用的 AI 模型。
2. 在“设置 › 数据来源”启用“个人记忆”，允许 AI 读取和操作记忆。
3. 在“设置 › 智能配置”打开“开启记忆”，允许自动提炼与整理。
4. 点击同页的“记忆文件”（“在访达中显示 MEMORY.md”），打开文件所在目录，用文本编辑器查看内容。

记忆保存在本机 `~/Library/Application Support/KulaHere/Memory/`，由 Markdown 文件组成：

| 文件 | 内容与用法 |
| --- | --- |
| `MEMORY.md` | 简短索引，包含“关于我”“偏好”“主题文件”；启用个人记忆后，非空索引会随 AI 请求提供给模型 |
| `projects.md` 等主题文件 | 长期项目或某个主题的细节；索引列出文件及说明，AI 需要时再读取 |
| `.previous/` | 最近一次自动整理前的文件副本；在访达中按 `Command + Shift + .` 可显示隐藏文件 |

设置页现在提供开关和文件入口。查看、修改和删除内容通过 AI 对话或文件编辑完成。

### 明确让 AI 记住、纠正或忘记

在对话中直接说明要求，例如：

- “记住，以后默认用中文回复我。”
- “纠正我的会议偏好：以后优先安排在下午。”
- “忘记记忆里关于我旧工作城市的那一条。”
- “读取 projects.md，看看你记住了我的哪些长期项目。”

明确要求保存、纠正或删除记忆时，默认自动审批模式可直接执行。请查看工具执行结果，再到文件中核对；只有 AI 回复“记住了”不代表已经保存。目标不明确或文字匹配不到时，先让 AI 读取对应文件再修改。

也可以直接编辑 Markdown 文件：稳定事实放在“关于我”，通用偏好放在“偏好”，较长细节放入主题文件，并在索引的“主题文件”下保留链接和一句说明。尽量让索引简短；正在进行的对话已收到旧上下文时，修改后用新对话核对。

### 哪些内容会自动记住

自动提炼主要保留用户明确表达、以后仍有用的信息：稳定身份事实、长期偏好、持续数周以上的项目或目标。一次性问题、工具执行过程、临时日程与待办、第三方网页内容，以及没有依据的推测，都不应成为长期记忆。多数对话不会产生新记忆，这是正常结果。

自动提炼会等对话空闲至少 30 分钟，再在结束一轮 AI 回复或开启新对话时尝试处理。它需要记忆开关、个人记忆来源和模型配置都可用，不会到点自行启动，也不会每轮立即写入。提炼会把新对话片段和有界的已有记忆发送给你配置的模型服务，因此可能产生额外模型费用。

记忆有变化或索引过长时，自动整理会在上述机会运行，两次尝试至少间隔 6 小时。整理会合并重复内容、更新新旧说法、移除明显过时或临时的内容，并把细节移到主题文件。整理前保存一份 `.previous/` 副本，它会在下一次整理时被替换，并非完整版本历史。

### 暂停与删除

关闭“设置 › 智能配置 › 开启记忆”会暂停自动提炼和整理，已保存的文件仍在，AI 仍可读取记忆或执行你明确要求的记忆操作。需要同时停用这些能力时，在“数据来源”关闭“个人记忆”。两个开关都不会自动删除文件。

忘记一条记忆会从当前文件删除对应行；旧整理副本可能仍有该内容。删除对话也不会自动删除已形成的记忆。需要彻底清理本机记忆时，先退出 Asky，备份需要保留的内容，再检查 `Memory/`（含隐藏的 `.previous/`）。旧版数据库中已确认或固定的记忆可能在索引不存在时重新迁入；完整重置方式与备份边界见[隐私政策草案](../PRIVACY.md)。

### 情境提醒与后台 AI

在“设置 › 数据来源 › 情境提醒”开启“主动提醒（冲突、出行准备、重要日期）”，并授予通知及所需系统来源权限。Asky 需要保持运行，相关来源也需要有可用数据。

“后台 AI 判断（默认关闭）”是独立开关，与自动记忆提炼不同。开启后，模型会结合日程、未完成提醒事项和记忆索引寻找需要准备或安排时间的事情，相关内容会发送给模型服务。日常建议默认无声、每天最多 2 条；不保证每次日程变化都会生成建议。

如果同时开启“短信读取”并授予完全磁盘访问，后台 AI 还会分批从最近 30 天的短信与 iMessage 中提炼待办事项。短信原文不写入长期记忆，事项摘要用于后续建议；关闭短信读取会清空这些摘要与处理进度。

## 插件与 MCP

基础使用无需安装插件。需要扩展功能时，打开“设置 › 插件”，按需选择官方插件或公开 GitHub 仓库，完成安装与配置后启用。插件可以更新、回退、停用和卸载；它们执行可信本机代码，不提供沙箱，仅安装你信任的来源。详细依赖与配置见[插件指南](plugins.md)。

MCP 用于让其他支持 MCP 的 AI 客户端连接 Asky 本地工具。在“设置 › 智能配置”创建接入实例，复制配置到目标客户端并保存只显示一次的凭据。Asky 需要运行；每个实例单独授权，外部写入按应用确认规则处理。接入详情见[原生工具与 MCP](native-tools-and-mcp.md)。

## 更新与常见问题

### 如何更新

打开“设置 › 关于 Asky”，点击“检查更新”。发现新版本后点击“安装更新”，应用会下载、校验并替换，然后自动重新打开。应用所在目录需要可写；若提示安装位置有问题，先移到“应用程序”。

### 快捷键没反应

确认 Asky 已运行，再到“设置 › 触发快捷键”查看注册状态。提示占用时更换组合键；也检查是否同时运行了旧版本或开发版本。可先从菜单栏打开对应功能。

### 搜索不到文件或 Chrome 内容

文件：检查“通用 › 文件搜索范围”，重新添加实际所在目录。书签：检查“系统权限 › Chrome 书签与链接搜索”，授权后重新打开搜索。标签页：确认 Chrome 正在运行，并允许自动化控制 Chrome。

### 剪贴板没有记录，或不能直接粘贴

检查“记录剪贴板历史”是否开启、来源应用是否被排除，再复制一条新内容。Asky 不会补录启动前的历史。不能直接粘贴时，授权辅助功能，或使用卡片“复制”后手动粘贴。文件显示原始内容不可用时，从新位置重新复制文件。

### AI 报错或不能操作系统

先在模型设置中点击“保存并检查”（或“重新检查”），并确认网络连接。确认 API 地址、模型名、Key 与服务匹配；工具操作还需要模型具备工具能力、来源已开启、系统权限已授权。工具报错时可展开错误详情；未完成的操作不要当作成功，创建结果不明确时先到系统应用核实再重试。

### 记忆没有出现，或 AI 仍使用旧信息

先检查“个人记忆”来源、记忆开关和模型配置。自动提炼需等对话空闲至少 30 分钟，并在后续 AI 使用时尝试；临时内容通常不会保存。想立即保存时明确说“记住……”，查看工具结果和 `MEMORY.md`。主题细节在索引链接的文件里。纠正后开启新对话核对；若整理有误，可先暂停自动记忆，再参考 `.previous/` 手动恢复。

### 权限看起来开启，但仍然不能用

在“设置 › 系统权限”查看当前状态。辅助功能和屏幕录制可点击“去授权”或“重新授权”，按浮窗提示把 Asky.app 卡片拖入系统设置并启用；屏幕录制开启后需要重启 Asky。旧版本升级后可能需要重新授权。

### 修改语言或外观

在“设置 › 通用 › 外观”选择应用主题或应用语言。语言更改在下次启动时生效；AI 回复和用户内容不会随界面语言自动翻译。

### 我的数据会发到哪里

本地搜索和剪贴板无需模型服务。使用 AI 时，消息、附件及任务需要的已授权资料会发送到你配置的模型服务；联网搜索还会把搜索词发送给 Bing。Asky 当前没有向项目作者上传用户数据的接口。详细保存、删除和第三方处理说明见[隐私政策草案](../PRIVACY.md)。

需要报告问题时，记录 Asky 版本、macOS 版本、操作步骤和错误提示，提交到 [GitHub Issues](https://github.com/Niall-Young/Asky/issues)。分享日志或截图前，请移除 API Key 和私人内容。
