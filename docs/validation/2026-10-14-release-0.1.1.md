# Asky 0.1.1 Release

日期：2026-10-14。远端最新已发布版本为 v0.1.0，按 patch 递增至 v0.1.1；构建号从 24 递增为 25。macOS 15+、Apple Silicon。

## 本次更新

- 应用索引持久化到磁盘，并后台预热应用搜索、图标和 Spotlight，加快重启后首次检索。
- 剪贴板面板支持标题区域拖动，每次打开回到默认位置。
- 浮窗使用系统原生窗口阴影，改善浅色玻璃文字可读性。
- 更新替换后刷新 Launch Services 缓存，设置窗口 Dock 图标显式使用当前应用图标。
