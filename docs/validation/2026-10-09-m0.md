### V04 进程生命周期：已在测试中验证

### V08 MCP：部分验证，两处实现偏离原文档

**偏离一：不使用官方 Swift MCP SDK，改用无依赖的 `MCPStdioServer`。**
- 0.12.1 版依赖 swift-nio，本机拉取依赖失败。
- 0.9.0 版无法在 Swift 6.3 下编译。
- `MCPStdioServer` 只实现 initialize、ping、tools/list、tools/call。

**偏离二：Bridge 与 App 之间不用 XPC，改用 Unix domain socket。**
- 路径为 `~/Library/Application Support/KulaHere/mcp.sock`，文件权限 0600，所在目录 0700。
- 用 `getpeereid` 校验对端为同一用户。
- 最多 8 个连接，单帧上限 1 MiB。
- 理由：ad-hoc 签名的自用构建无法使用 XPC 的签名身份约束。

测试通过的项目：
- 伪造确认被忽略（`forgedConfirmationIsIgnoredForMCP`）。
- 实例生命周期、作用域与撤权；确认期间撤权会阻止执行。
- App 未运行时返回可恢复的不可用（`appNotRunningIsRecoverableUnavailable`）。
- socket 仅属主可访问。
- Bridge 二进制端到端调用。

未验证：
- 未接入真实 MCP 客户端（Claude Desktop 等）。
- 未在正式签名构建中验证。
- 如果以后改回 XPC 或官方 SDK，需要重新运行 V08。
