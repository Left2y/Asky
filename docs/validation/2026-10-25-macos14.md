# macOS 14 兼容

## 范围

- App、内置 asky-mcp 及两个 SwiftPM 清单最低版本统一为 macOS 14.0。
- macOS 14 与 15 共用全部业务功能及原生背景模糊路径。14 的设置使用原生 grouped Form，15+ 保留原有卡片；不承诺像素完全相同。
- 14 的聊天保留初始底部、流式跟随、向上阅读及回到底部按钮，使用 ScrollViewReader 与 AppKit 滚动区域通知；15+ 保留 ScrollPosition 实现。
- 14 的聊天及剪贴板标题栏空隙通过 AppKit performDrag 拖动。15+ 保留 WindowDragGesture。
- 用 OSAllocatedUnfairLock 替代仅在 15+ 可用的 Synchronization.Mutex。新增资源释放并发与回调重入测试；不改工具权限边界。
- Debug 参数 `--preview-macos14` 强制选择 14 的材质、表单、滚动与拖动分支，便于在新系统检查。

## 实际检查

主机为 macOS 27.0.1、Apple Silicon，Xcode SDK 27.0。以下不是 macOS 14/15 实机验收。

- `xcodegen generate`：通过。
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Debug -derivedDataPath build/macos14/DerivedData build`：通过。
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Release -derivedDataPath build/macos14/DerivedData build`：通过；Release App 与内置 MCP 的两个架构均回读 `minos 14.0`，不因此承诺 Intel 支持。
- `(cd Packages/KulaCore && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test)`：313 个测试、13 个测试可执行文件通过，包括并发结束与释放回调重入检查。
- `(cd MCPBridge && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build)`：通过。
- 产物 Info.plist 的 LSMinimumSystemVersion 为 14.0；`xcrun vtool -show-build` 回读 App 与内置 asky-mcp 均为 `minos 14.0`。
- `ASKY_DERIVED_DATA="$PWD/build/macos14/DerivedData" python3 App/Tests/run-launcher-window-regression.py --preview-macos14`：广泛回归未通过，系统滚轮辅助进程场景在获取结果滚动视图时触发 nil；随后已终止该辅助进程。
- 单独执行启动器 `--preview-macos14 --bottom-clearance`：合成滚轮事件未推动结果，未通过。未强制兼容分支的对照同样未通过（滚动后的选择保持断言）；不能记为旧系统滚轮验收通过。
- 单独执行启动器 `--preview-macos14 --shell-lifecycle`：第 90 次循环出现查询被清空、无结果，未通过。
- 单独执行启动器 `--preview-macos14 --first-presentation`：浅深色均通过，检查首次尺寸、裁剪、同步输入焦点与 9 次重用。

- `ASKY_DERIVED_DATA="$PWD/build/macos14/DerivedData" python3 App/Tests/run-settings-regression.py --preview-macos14`：浅深色各设置页面快照、MCP 控件检查完成；随后在权限页恢复的标题/选择断言失败（测试硬编码中文标题，本次界面为英文），整体不记为通过。原生 Form 延迟创建屏幕外行，MCP 检查已调整为先滚动到对应控件。

- `ASKY_DERIVED_DATA="$PWD/build/macos14/DerivedData" python3 App/Tests/run-agent-reply-regression.py --preview-macos14 --macos14-checks`：通过。检查聊天原生模糊、原生拖动区域、可滚动消息列表与浅深色快照；人工查看快照确认向上滚动后显示回到底部按钮。位置检测已使用 AppKit bounds/frame 通知，覆盖程序滚动与内容高度变化。此检查不包含真实鼠标拖动、滚轮或流式网络消息验收。
- 同一聊天回归二进制以 `--preview-macos14` 执行模型回归：澄清与持久化问题、最终回复、取消、耗时、附件恢复、新对话清理通过。

日志、生成工程、SwiftPM 及 Xcode 构建产物、截图均在现有忽略目录内，无需新增忽略规则。

## 发布与验收边界

本次不发布安装包。仓库 Cask 固定的 0.2.9 DMG 仍要求 macOS 15，保留其版本、校验值和系统限制；不得将旧包误标为支持 14。后续发布使用本次源码构建新 DMG/ZIP 后再更新 Cask。

仍需 macOS 14/15 实机检查：安装与冷启动、权限、登录启动、系统搜索与剪贴板、窗口真实拖动、聊天滚动及流式跟随、设置操作、Agent Node runtime 与 MCP 客户端连接。当前主机的回退分支检查不能替代上述项目。
