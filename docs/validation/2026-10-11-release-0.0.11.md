## 实际运行

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Release -derivedDataPath build/Release010DerivedData build
npm ci --omit=dev --prefix build/release-runtime-0.0.11
python3 scripts/package-release.py --version 0.0.11 --build 11 --derived-data build/Release010DerivedData --runtime build/release-runtime-0.0.11 --node-root build/node-v22.23.3-darwin-arm64
```

## 用户验收

先从 [0.0.10 Release](https://github.com/Niall-Young/Asky/releases/tag/v0.0.10) 下载 DMG 并安装到“应用程序”。启动 0.0.10，在“设置 › 关于 Asky”检查更新，应发现 0.0.11；安装并确认后，应下载、校验、退出、替换旧包并自动重新打开，版本变为 0.0.11（11）。这条真实应用内升级链路仍待用户本次测试，未在记录中计为通过。
