## 实际运行

```sh
(cd Packages/KulaCore && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test)
(cd AgentRuntime && npm test)
(cd MCPBridge && DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build)
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Release -derivedDataPath build/Release010DerivedData build
npm ci --omit=dev --prefix build/release-runtime-0.0.10
python3 scripts/package-release.py --version 0.0.10 --build 10 --derived-data build/Release010DerivedData --runtime build/release-runtime-0.0.10 --node-root build/node-v22.23.3-darwin-arm64
```

- 完整核心测试通过；AgentRuntime 6 项测试通过；MCP Bridge 与 Release App 构建通过。
- Node.js v22.23.3 arm64 压缩包按本次下载的官方 SHA-256 清单核验通过；二进制与压缩包内容一致。
