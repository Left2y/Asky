# 设置分类与模型凭据复用验证

日期：2026-10-10。

## 实现

- 760 × 590 pt 原生设置窗口，顶部图标导航：外观、模型、触发快捷键、别名与快捷指令、更多设置。原有数据来源、系统权限、记忆与 MCP 页面保留。
- 主题支持跟随系统、浅色、深色，应用于 NSApplication；偏好独立存于 `app.preferences.v1`，不改变旧 `AppSettings` 解码。
- 模型支持 OpenAI、DeepSeek 和自定义 OpenAI-compatible 地址，模型名可填写；API Key 仍仅保存在钥匙串。API Key 字段不回填，空值保留原密钥。
- 保存或明确读取密钥后，仅在应用进程内复用；能力检查与 Runtime 共用凭据会话。并发读取合并；新 Key 替换缓存，退出后缓存消失。不会自动读取真实 Key 做测试。
- 快捷键通过原生按钮录制并实时注册 Carbon 热键，失败保留原快捷键；别名支持应用、macOS 快捷指令，网页关键词保留。新增应用打开、快捷指令列表和运行入口经 ToolService。

未授权或读取真实 API Key，未调用付费模型 API，未验证重启后的真实钥匙串授权或实际 AI 回复。不能声称所有系统密码提示已消失。设置中保存新 Key 会直接缓存本次输入，后续能力检查和 Runtime 无需再次读取该 Key；退出重启后 macOS 仍可能要求首次访问授权。未打包 Release、未安装到 Applications。
