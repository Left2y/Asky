# Asky 0.0.19 Release

日期：2026-10-13。版本 0.0.19/build 19，macOS 15+、Apple Silicon。

以上一已发布版本 v0.0.18 为基准递增 patch。本次将发布包改用固定的 `Asky Local Signing` 证书，保持主应用与内置执行文件的签名身份连续。证书仅包含产品签名名称；私钥保存在登录钥匙串，不进入分发包。证书 SHA-1 为 `BBCC4AB3786640961FFD5BF63808AD00761AFB3B`。

## 已执行检查

- KulaCore：`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`，241 项测试通过。
- AgentRuntime：`npm test`，TypeScript 编译和 9 项测试通过。
- MCPBridge：`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift build` 通过。
- `xcodegen generate` 通过；`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Asky.xcodeproj -scheme Asky -configuration Release -derivedDataPath build/Release019DerivedData build` 通过。
- 生产 runtime：`npm ci --omit=dev --prefix build/release-runtime-0.0.19` 通过。
- Node v22.23.3 darwin-arm64：下载包与本轮官方 SHA-256 清单匹配，源二进制与压缩包内容一致。下载包 SHA-256 为 `23b25245dcfb9af7262f8ff142e9e2e0af025368117329e7a7458a51e5922f53`。
- 已有两个不同内容的签名副本通过身份连续性检查，见[本机签名验证](2026-10-13-local-signing.md)。

从旧 ad-hoc 版本切换后可能需要重新授权一次。没有将签名身份验证视为真实 TCC 升级验收；辅助功能、屏幕录制等权限在实际升级后的保留、真实模型对话及 macOS 15 实机验收均未完成。
