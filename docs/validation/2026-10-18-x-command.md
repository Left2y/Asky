# X 搜索指令

新增内置网页指令 `x`，默认启用，使用 `https://x.com/search?q={query}`。输入 `x` 后按空格进入 X 搜索模式；关键词沿用现有安全编码，回车通过现有 ToolService 网页打开流程执行。设置支持启停、修改触发词与恢复默认。中文和英文本地化、README 与 PRD 已同步。

X 品牌图标来自 `https://x.com/favicon.ico`（官网返回 32 × 32 PNG），随应用打包，设置、输入模式与结果行共用 `CommandIcon`。
